# W1 记忆卡片

这个文件是**卡片示例**，也是你的第一个卡组。

写法很简单：一行以 `-` 开头，问题和答案用 `::` 分隔。

```md
- temperature 调高会让输出更随机::对
```

构建时会自动扫描 `notes/` 下所有 Markdown，把这样的行抽成 `/cards` 页面的卡片。卡片正文不会在笔记页显示成卡片样式——它只是一行普通列表，但会在复习页出现。

## 大模型参数

- temperature 调高会让输出更随机::对
- 同时把 temperature 和 top_p 调高是推荐做法::错，一般只调其中一个
- top_p = 0.9 表示只从累计概率前 90% 的词里采样::对
- temperature = 0 时模型输出仍然可能不同::对，浮点运算和批处理会导致细微差异
- max_tokens 限制的是输入长度::错，限制的是输出 token 数
- 中文里 1 个汉字大约等于 1 个 token::错，通常约 1.5 到 2 个 token

## Python 对照 Java

- Python 的 list 对应 Java 的什么::List，有序可重复
- Python 的 dict 对应 Java 的什么::Map，键值对
- 空 set 的写法是什么::set()，因为 {} 是空 dict
- Python 判断 None 用什么::is None，不要用 == None
- Python 的 == 是值比较还是引用比较::值比较，等价于 Java 的 equals
- Python 的 is 是值比较还是引用比较::引用比较，等价于 Java 的 ==
